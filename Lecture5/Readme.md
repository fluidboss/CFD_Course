In Lecture 5 we cover two important techniques of generating a mesh, including

(a) creation of a structured mesh using blockMesh. 

(b) creation of a complex mesh that conforms to the shape of an object expressed through an stl image.

The examples include both the case of subsonic flow past a 2D cylinder and a NACA0012 aerofoil and a transonic flow past a NACA0012 aerofoil.
